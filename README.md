# Agentic AI Real Estate Assistant

An AI-powered real estate assistant that helps users discover properties, answer property and market questions, qualify leads, and keep CRM records up to date.

## AI Agents

- **Search Agent**: Finds relevant properties based on user requirements.
- **Knowledge/RAG Agent**: Answers questions using grounded property and real estate knowledge.
- **Lead Scoring Agent**: Evaluates and prioritizes prospective buyers.
- **CRM Agent**: Captures conversations, updates lead records, and supports follow-up workflows.

## Tech Stack

- n8n for workflow orchestration
- LangChain for agent and retrieval workflows
- Groq/Hugging Face LLM for language intelligence
- Supabase pgvector for vector storage and retrieval
- PostgreSQL for application data
- React + Tailwind via Lovable for the frontend
